## 核心约束

本工具采用**源文件与备份文件直接建立 NTFS 硬链接**的模式。它主要用于保留被误删的文件路径：删除源路径后，备份路径仍能访问同一文件。原地写入、覆盖、加密或损坏文件内容会同时影响所有硬链接，不能据此恢复修改前的内容。用户界面和说明必须持续明确这一点。
