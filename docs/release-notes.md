## 升级与下载

先从托盘退出旧程序。安装到 Program Files 等受保护目录时，在同一账户下右键安装包“以管理员身份运行”，选择原目录覆盖升级。绿色版覆盖程序文件并保留原 data 文件夹。

- `*-Setup-x64.exe`：安装版。
- `*-Portable-x64.zip`：绿色版。
- `SHA256SUMS.txt`：附件校验值。

Windows 10 22H2 / Windows 11，x64；内置 .NET 运行时。安装包未签名。硬链接共享内容，不提供跨盘副本或历史版本。
