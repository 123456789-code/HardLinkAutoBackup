# HardLinkAutoBackup 1.1.1

- 同时提供简体中文安装版与绿色版，均内置 .NET 运行时。
- 安装版默认安装到当前用户目录，提供开始菜单入口及可选桌面快捷方式。
- 覆盖安装保留配置，卸载保留 data 和备份文件。
- 安装、卸载前检查程序是否已退出；当前安装位置仍有登录自启时，要求先在程序设置中关闭并保存。
- 补齐项目 MIT 许可证文件到分发包。
- 新增 GitHub 自动构建、回归验证和双产物发布。

## 下载选择

- `*-Setup-x64.exe`：安装版。
- `*-Portable-x64.zip`：绿色版，完整解压后运行 EXE。
- `SHA256SUMS.txt`：两个文件的 SHA256 校验值。

系统要求：Windows 10 22H2 / Windows 11，x64。安装包未进行代码签名。
硬链接共享内容，不提供跨盘副本或历史版本；配置和使用方法见包内《使用说明》。
