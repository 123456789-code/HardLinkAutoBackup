# HardLinkAutoBackup 1.1.3

- 安装前检查目标目录和已有卸载器的写入权限，避免安装到中途才出现 unins000.exe“拒绝访问”。
- 提前显示失败路径和处理提示，支持返回更换目录；默认用户目录仍免管理员安装。
- 新增目录写入受限、卸载器只读的云端回归，同时验证失败时原程序和配置不被改写。
- 包含 1.1.2 的滑块残影修复，继续提供中文安装版与自包含绿色版。

## 升级与下载

先从托盘退出旧程序。安装到 Program Files 等受保护目录时，请右键安装包“以管理员身份运行”，使用同一 Windows 账户，选择原目录覆盖升级。不要跳过失败文件；管理员运行仍失败时，根据提示检查旧文件是否只读或被占用。
绿色版完整解压覆盖程序文件，保留原 data 文件夹。安装升级与卸载均保留用户配置和备份。

- `*-Setup-x64.exe`：安装版。
- `*-Portable-x64.zip`：绿色版。
- `SHA256SUMS.txt`：两个文件的 SHA256 校验值。

系统要求：Windows 10 22H2 / Windows 11，x64。安装包未进行代码签名。
硬链接共享内容，不提供跨盘副本或历史版本；配置和使用方法见包内《使用说明》。
