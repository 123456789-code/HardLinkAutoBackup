# HardLinkAutoBackup 1.1.4 使用说明

## 1. 安装或解压运行

安装版：运行 `*-Setup-x64.exe`，默认安装到当前用户的 `%LOCALAPPDATA%\Programs\HardLinkAutoBackup`，不要求管理员权限。开始菜单提供程序入口，桌面快捷方式可选。安装不会自动打开程序或开启自启。

覆盖升级保留 `data`。安装和卸载前请从托盘退出程序；若当前安装位置仍注册登录自启，卸载会要求先在程序设置中关闭并保存。卸载只移除安装文件和快捷方式，保留配置及备份。

绿色版：

将发布 ZIP 解压到可写目录，运行 `HardLinkAutoBackup.exe`。保留整个文件夹，不能只取 EXE；已包含 .NET 10 运行时，不需要安装组件。发布目标为 Windows 10/11 x64；具体系统兼容性以 .NET 10 支持范围为准，未在所有系统版本验证。当前包未进行代码签名。

默认不开启自启和管理员权限；关闭窗口默认隐藏至 Windows 右下角通知区域。托盘可能收纳在“显示隐藏的图标”中。双击图标打开窗口；托盘“退出程序”才完全停止。

程序所有配置、扫描状态、日志位于 EXE 同目录 `data`。启动时先检查实际写入权限。如果位于 Program Files 等受保护目录而无法写入，会说明原因并询问是否以管理员身份重启；同意且授权成功后开启“管理员权限启动”设置。拒绝或取消 UAC 会给出退出/迁移提示，不继续带着错误运行；已经是管理员仍不可写时，不循环请求提权。程序不会修改目录 ACL，也不会偷偷改用 AppData 保存配置。

界面固定为简体中文。发布包只保留 `zh-Hans` 等简体中文资源；这些原本是 .NET/WinForms 的本地化资源，不是额外安装的语言软件。`licenses` 文件夹是运行时许可证，请保留。Windows 自带的文件选择器等系统界面的语言仍可能由系统决定。

## 界面与缩放

按钮会根据文字自动调整宽度，较窄窗口中的操作栏可换行。任务编辑和设置页高度不足时可滚动，底部保存/取消按钮保持可见。首次打开会限制窗口不超出屏幕工作区。长路径可悬停查看，设置页的数据路径也可以选择复制。

自动备份使用滑块：蓝色向右为开启，灰色向左为关闭，同时显示状态文字；可点击或使用 Tab 聚焦后按空格切换。

底部使用提醒右侧的“不再提示”会立即保存选择，重新打开程序后仍隐藏；在“程序设置”中启用“显示底部使用提醒”并保存即可恢复。

新版文件夹链环图标用于程序文件、窗口和托盘。若资源管理器仍显示旧图标，可先在新解压目录查看；程序不会修改系统图标缓存。

## 2. 新建任务

点击“新建任务”，输入或选择：

- 任务名称（可空，保存时取目录名）。
- 已存在的本地源目录。
- 同一 NTFS 卷上的备份目录，可以尚不存在。
- 自动备份开关和完整扫描间隔（10 秒～365 天）。
- 可选的排除路径：每行一个源目录下的相对路径，例如 `cache` 或 `temp\draft.txt`，不支持通配符和 `..`。

源和备份不能相同或嵌套；每个任务独占备份目录，任何备份目录也不能与其他源目录重叠。因此不能直接选择整个卷根目录为源；请按不包含备份位置的子目录建任务。目录联接点、符号链接、网络共享不支持。空目录不单独备份。

保存启用的任务后首次完整扫描。新增文件和目录重命名在事件静默约 2 秒后处理；连续事件最长约 15 秒后合并触发，已有扫描、重试退避等会延后执行。完整扫描按上次完整扫描结束时间计算，用于补漏。休眠恢复和重新启动会补扫一次，不唤醒电脑。

## 3. 硬链接的实际行为

文件直接硬链接，不复制内容，不生成 N 代快照。

| 操作 | 结果 |
| --- | --- |
| 删除源文件 | 备份路径仍可访问原文件。 |
| 原地修改源或备份内容 | 同一对象的所有硬链接同步变化。 |
| 重命名源文件或目录 | 原备份保留，新路径可新增链接。 |
| 同名源路径被新文件对象替换 | 原备份不覆盖，新对象另存到冲突区。 |
| 移除任务、关闭自动备份或退出 | 已有硬链接保留。 |

冲突区为备份目录下的 `.hlab-conflicts/<任务ID>/<卷及文件ID>/<源相对路径>`。原同名备份不一定是当前源内容；“异名保存”提示时应在该区查找。重复扫描不会不断新建同一对象的冲突链接。源目录顶层不能使用 `.hlab-conflicts` 名称。

原地覆盖、勒索加密、磁盘损坏无法靠硬链接恢复。也不要通过编辑备份文件验证“副本独立性”，这会改变共享内容。需要独立存档时，应另行复制到不同介质。

“本次链接”仅统计最近这次扫描确认的目录项，不表示所有备份数量。单文件变化扫描通常显示 1；资源管理器累计文件大小也不能代表实际新增占用空间。

## 4. 开关、取消与错误

总开关与任务开关同时开启才会自动备份；关闭自动开关不强行中断已经在执行的扫描，手动“立即扫描”始终可用。

同一任务不会并行扫描。运行时重复点“立即扫描”会合并为一次追加扫描；“取消扫描”清除追加请求和当前事件队列，自动扫描等到下个周期再恢复，新手动请求可立即运行。文件级 I/O 调用结束后才能响应取消。

扫描失败保留已有结果，约 60 秒后完整重试；监控不可用会每隔约 30 秒尝试重建，周期扫描仍然有效。错误可见于扫描详情、任务提示和日志。失败详情最多保存前 100 项，总失败数仍累计。事件遗漏及文件在建链前已被删除无法保证挽回。

任务首次确认卷后保存卷身份，盘符指向另一个卷时停止写入。确实更换磁盘时，核对源和备份后编辑保存任务重新绑定；旧备份不搬迁。

## 5. 登录自启和管理员权限

程序设置只包含登录自启、管理员启动、后台驻留和提醒显示四个滑块。自动备份总开关位于主界面，任务自身的开关位于任务编辑窗口；设置页不重复展示。自启实际指当前用户登录后启动，不是登录前运行的服务。

修改自启前会展示计划任务名 `HardLinkAutoBackup-<当前用户SID>`、程序路径、管理员选项与撤销方式。确认后才注册、更新或删除此任务。系统可能显示 UAC；普通文件夹通常不需要管理员权限，不支持切换到另一个管理员账户进行设置。

“核对自启状态”只读取这一任务的实际状态。“同步自启任务”按钮安排保存时按当前滑块状态同步任务或旧程序路径，点击“保存设置”后确认才执行；点击“取消”不执行。程序不会静默修复自启，也不会覆盖不属于本程序的同名任务。

管理员启动开关下次启动生效。取消手动启动的 UAC 时，可选择关闭此配置并以普通权限运行；如果之前注册过提升权限自启，还需在设置中同步自启任务。系统任务和配置文件不在同一个事务中，遇到保存中断时通过“核对”确认，再显式同步。

## 6. 配置恢复、升级与卸载

- 配置：`data/settings.json`，上次保存副本为 `settings.json.bak`。
- 扫描状态：`data/state.json`，损坏时记录错误并重新扫描，不影响任务配置。
- 日志：`data/activity.log`，约 2 MB 轮转至 `.previous`。
- 配置损坏：启动时可确认从备份恢复，损坏原文件另存为 `settings.damaged-*.json`，不会静默清空任务。
- 升级：退出旧程序，先备份 `data`，解压新版本到新目录，将 `data` 复制过去；确认任务后运行。搬动路径后在设置中核对并同步自启。
- 卸载：先在设置中关闭自启并确认，再从托盘退出。自行删除程序文件夹即可；备份目录中的硬链接不会自动删除。也可在 Windows 任务计划程序中删除上述精确名称的任务。

不要在程序运行时手工编辑配置或并行运行多个版本操作同一组备份目录。

## 7. 校验发布包

ZIP 同目录提供 `.sha256`，解压目录提供每个发布文件的 `SHA256SUMS.txt`。PowerShell 的 `Get-FileHash -Algorithm SHA256` 可核对文件。校验清单不包含后续用户生成的 `data`。

此版本已通过项目内真实 NTFS 回归测试。未自动在用户系统上注册任务、触发 UAC、注销或休眠；这些系统集成行为尚需在用户同意的环境实测。详见源码中的 `docs/release-validation.md`。

## 安装提示“拒绝访问”

先关闭安装程序，不要选择“跳过此文件”。从右下角托盘退出旧程序后重试。
默认安装目录位于当前用户目录，不需要管理员权限。若自选 Program Files 等受保护目录，请右键安装包，选择“以管理员身份运行”，使用同一 Windows 账户，再选择原目录升级。
安装器保留当前用户安装范围，不自动切换账户、不修改目录权限。若不希望提升权限，返回并选择默认用户目录；迁移目录需自行保留原 data，并在程序内重新同步登录自启路径。
1.1.4 会在复制程序文件前验证写入能力。即使可创建新文件，旧 unins*.exe / unins*.dat 只读或被占用也会提前拦截；提示会列出具体失败路径。已经以管理员运行仍失败时，应处理该文件的只读、占用或访问限制。
若安全软件告警，先停止操作并核查告警，不添加白名单。安装前检查通过后权限或占用仍可能变化，此时应取消安装并处理实际错误，不能跳过文件。
