# 需求说明

状态：1.0.0 交付需求（2026-10-19）；使用说明见 user-guide.md，验证边界见 release-validation.md。

## 1. 目标与范围

为 Windows 10/11 提供有图形界面的多任务硬链接防误删工具。用户为每个任务选择源目录和备份目录，程序在用户登录后启动，可在通知区域驻留，持续监控并按设定周期扫描，以便为新增文件建立硬链接。目标支持最多 100 个任务，但不能因任务多而同时启动 100 次密集扫描。

本工具不提供多代快照、版本保留数、自动清理、跨卷复制备份或云备份。备份中已经存在的文件不得因源文件被删除而自动删除。

## 2. 硬链接语义

1. 每个源文件在备份目录中有对应的相对路径；目录结构由程序创建，硬链接仅用于文件。
2. 源与备份必须处于同一个 NTFS 卷。创建任务时验证；运行中卷发生变化时暂停该任务并报错。
3. 发现新增文件时，仅当目标路径尚不存在时创建硬链接。创建前后均不读取或复制文件内容。
4. 源文件被删除时，程序保留备份路径，不执行反向删除。源文件被重命名时，旧备份路径保留，新路径可新增硬链接，因此同一文件可能出现多个备份路径。
5. 对同一文件的原地修改会立即反映到源和备份的所有硬链接中；备份不保存修改前的内容。界面不得用“历史版本”“可恢复覆盖前内容”等表述。
6. 源路径被新文件对象替换，而备份中同名路径已指向旧对象时，必须保留旧对象，并另行为新对象建立硬链接。具体呈现规则见第 8 节。
7. 对已存在的目标文件，必须检查它与源文件是否为同一个文件对象；不能仅靠文件名、大小或修改时间认定已备份，也不能覆盖不明来源的文件。
8. 不自动删除、清理或改写源目录中的任何对象。所有自动操作应限制在任务指定的备份目录和程序自身的数据目录内。

> 这是一种防误删方案，不是独立副本。源卷损坏、文件内容原地被覆盖或加密时，备份路径不能提供独立保护。

## 3. 任务

每个任务的必填或核心字段：

| 字段 | 行为 |
| --- | --- |
| 源目录 | 选择一个现存的本地目录；卷根目录因无法与同卷备份位置互不嵌套而拒绝；运行时不可访问则记录错误并等待重试。 |
| 备份目录 | 选择该任务专用的目录；必须与源在同一 NTFS 卷，且不得互相嵌套。 |
| 周期自动备份开关 | 关闭时不执行该任务的自动监控和周期扫描；仍可手动扫描。 |
| 备份周期 | 按固定间隔执行完整扫描，界面显示下次计划时间；到期而上次扫描未结束时不重叠执行。 |

任务支持新建、编辑、启用/暂停、立即扫描、查看结果、删除任务。删除任务默认只移除配置，保留备份数据；任何备份数据删除都不属于第一版功能。修改周期即时影响下次扫描；修改源目录或备份目录时需要重新进行路径校验和完整扫描，不自动搬迁既有备份文件。

建议第一版提供简单排除规则：按相对路径排除目录或文件。排除规则只影响之后的扫描，不删除已备份对象。系统属性和隐藏属性本身不应成为默认排除理由。

## 4. 全局设置与程序生命周期

| 设置 | 精确定义 |
| --- | --- |
| 开机自启 | 当前用户登录 Windows 后启动本程序；不要求登录前运行。关闭开关时移除本程序创建的自启项。 |
| 管理员权限启动 | 默认关闭。打开后，手动启动需经过 Windows 提权，登录自启以提升权限运行；界面须说明适用场景及生效时机。普通可访问目录不应要求管理员权限。 |
| 周期备份总开关（主界面） | 关闭时暂停所有任务的自动监控和周期扫描，不改变每个任务自己的开关；手动扫描仍可用。 |
| 关闭界面后台驻留 | 打开时关闭窗口仅隐藏到 Windows 通知区域；关闭时关闭窗口即退出进程，自动监控随之停止。 |

同一用户会话只运行一个程序实例。重复启动时激活现有窗口。托盘菜单至少包含“打开界面”“暂停/恢复自动备份”“立即扫描”“退出程序”。退出时停止接收新任务，正在进行的扫描可取消并记录未完成状态；下次启动执行补扫。关闭“后台驻留”时，窗口关闭行为与托盘“退出程序”一致。

自启关闭或程序退出不改变已有硬链接。切换自启或管理员设置属于本机持久配置操作，UI 应显示将创建、更新或移除的计划任务，并提供撤销方式。

## 5. 界面结构

### 主窗口

- 任务表格：任务名或 ID、源目录、备份目录、状态、已建立链接数、最近一次扫描时间、下次扫描时间、最近错误。
- 操作栏：新建、编辑、暂停/启用、立即扫描、查看日志、删除任务。
- 全局状态区：总开关状态、正在扫描的任务数、最近一次错误提醒。
- “已建立链接数”指成功确认的目录项数量；备份目录中显示的文件大小不能简单相加作为实际占用空间，因为多个硬链接可能指向同一文件。

### 任务编辑窗口

- 四个核心参数置于最显眼位置，路径通过文件夹选择器输入，并显示路径校验结果。
- 保存时校验同卷 NTFS 与互不嵌套；实际创建目录或链接遇到权限问题时在扫描结果中提示，不为验证而预先写入测试文件。
- 高级选项容纳排除规则和任务名称，不增加创建任务的必填负担。

### 设置窗口与提示

- 设置页仅显示登录自启、管理员启动、关闭后后台运行和使用提醒四个滑块。周期备份总开关保留在主界面，不在设置页重复。一次性同步自启操作使用按钮，保存时执行；取消则不执行。
- 明示硬链接共享内容的局限，特别是“原地修改会同时改变备份”。
- 扫描失败、监控失效、路径冲突或任务暂停时显示状态和可查看的错误信息；通知区域只提示需要用户注意的事件，避免每次扫描都弹窗。

## 6. 自动扫描行为

1. 启动、创建任务或恢复任务后进行一次完整扫描，以发现离线期间新增的文件。
2. 运行时使用文件系统事件尽快发现新增、移动和重命名；短时间大量事件合并处理，不为每个事件启动全目录扫描。
3. 按任务周期做完整扫描，修复文件系统监控事件遗漏。监控失败或缓冲区溢出时记录错误并安排完整扫描。
4. 同一任务扫描串行化；全局最多同时执行两个任务。用户点击“立即扫描”时，如果该任务已在扫描，则合并为一次待执行扫描。
5. 自动扫描不开机唤醒电脑；关机、休眠或程序未运行期间错过的周期，在下次程序运行时补做一次，不逐次补跑。
6. 扫描过程允许源文件消失或被占用：单个文件失败不终止其他文件，失败项进入本次结果并在后续扫描重试。

## 7. 路径和安全边界

- 拒绝源与备份相同、相互嵌套，以及任一任务的备份目录落入其他任务源目录的配置；避免扫描循环。
- 默认不递归进入目录联接点、符号链接等重解析点，也不为文件重解析点创建硬链接；在结果中列出跳过数，避免跨卷或循环。
- 使用 Windows Unicode 路径接口，不沿用参考程序对非英文文件名的限制；长路径若无法处理，应给出逐项错误，不能静默漏备份。
- 用户手动放入备份目录的同名文件不能被覆盖或删除。路径不可访问、非 NTFS、跨卷、权限不足、硬链接数量达到系统限制时均给出明确错误。
- 首次对含现有文件的备份目录运行时，逐项验证对象身份，不将同名但不同对象的文件视为成功备份。

## 8. Demo 中确定的产品决定

1. **同名路径对应新文件对象时的展示方式**：新对象的硬链接保存在 `.hlab-conflicts/<任务 ID>/<卷及文件 ID>/<源相对路径>`；原同名备份保持原位。稳定的文件 ID 使重复扫描不会不断新增冲突副本。备份目录的同名路径不一定代表当前源文件，界面以“异名保存”标明；源目录顶层的 `.hlab-conflicts` 名称保留给程序使用。
2. **任务删除后的备份数据**：当前定为一律保留，不提供程序内删除；若将来增加清理功能，需独立设计明确的确认流程。
3. **目标系统**：当前按 Windows 10/11 设计，不含参考程序的 Windows 7 兼容要求。

## 9. 第一版验收标准

- 能创建、编辑并运行多个任务；任务设置重启后仍在。
- 对同卷 NTFS 的新增文件创建硬链接，并验证源和备份指向同一文件对象；不会复制文件内容。
- 删除源文件、目录或重命名后，原备份路径仍在；不会因扫描而删除备份路径。
- 对源文件原地写入后，界面说明与实际硬链接行为一致；不会错误声称保留旧内容。
- 文件监控遗漏、程序重启或电脑休眠后，完整扫描能补建遗漏链接。
- 跨卷、非 NTFS、目录嵌套、不可访问和同名异对象等情况有明确错误，不覆盖已有文件。
- 关闭窗口、托盘驻留、退出和全局/任务开关符合第 4 节定义。
- 未启用自启时不创建系统启动项；禁用自启时移除由本程序创建的启动项。
