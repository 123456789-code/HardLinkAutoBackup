## 自动验证范围

| 类别 | 覆盖行为 |
| --- | --- |
| 硬链接 | 源/目标 ID 一致、幂等、共享写入、删源保留、重命名保留 |
| 冲突 | 同名替换、文件变目录、用户目标文件保留、冲突路径阻塞后的继续扫描和补建 |
| 路径 | Unicode、长路径、嵌套拒绝、保留名、程序数据目录保护、相对路径与越界排除拒绝 |
| 数据 | 配置加载、损坏不覆盖、备份恢复另存损坏文件、空任务拒绝、磁盘卷身份不符拒绝 |
| 增量 | 单文件扫描、父子路径合并、事件队列溢出、2000 文件负载 |
| 调度 | 首次扫描、真实文件事件、周期补漏、事件不推迟周期、配置不重置计划、总开关与手动运行 |
| 生命周期 | 取消清空追加请求、显式恢复通知补扫、恢复最近扫描结果、停止等待后台任务 |
| 自启定义 | XML 路径转义、普通/提升权限级别、交互式登录、无执行时长限制 |

“恢复通知”测试直接调用调度器入口，未实际让 Windows 休眠。“事件队列溢出”测试覆盖程序队列退回完整扫描，未人为制造 Windows 内核通知缓冲区溢出。

最初尝试用独占打开文件制造失败，但元数据查询/建硬链接不一定被该共享模式阻止，因此改为确定可复现的目标路径阻塞。未把这一测试宣称为实际 ACL 拒绝或所有文件锁场景的验证。

- 发布包包括使用说明、变更记录、逐文件 SHA256 清单；ZIP 旁有对应 .sha256 文件。

- 发布脚本每次创建新的时间戳目录，不覆盖旧发布目录或用户数据；构建下载与临时文件限制在项目 .local。
