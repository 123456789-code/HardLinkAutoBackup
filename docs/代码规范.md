## 第一章：核心顶层原则

1. **灭绝小驼峰（camelCase）**：业务代码中禁止出现任何 `myVariable` 这种写法，除非被迫调用第三方库的 API。
2. **消灭前缀**：禁止使用 `m_`、`_`、`g_`、`s_` 等任何匈牙利/下划线前缀。
3. **大括号不换行**：禁止`if`、`for`等语句的大括号换行
4. **后缀自增优先**：在 `++x` 与 `x++` 逻辑等价时，强制使用 `x++`。
5. **机器优先，人力次之**：优先使用 `.editorconfig` + VS“保存时格式化”，但允许推荐而非强制。

## 第三章：缩进、换行与空白

| 规则项 | 规定 | 强制力 |
| :--- | :--- | :--- |
| 缩进符 | **Tab**，宽度为 VS 默认（通常显示为 4 空格宽度） | 强制 |
| 行宽 | **不限**，由程序员自己判断是否过长 | 建议 |
| 大括号风格 | **K&R（不换行）**：`if (x > 0) {` | 强制 |
| `switch/case` 缩进 | `case` 与 `switch` **平齐**（不额外缩进） | 强制 |
| 指针/引用符号 | **紧贴类型名**：`int* ptr` | 强制 |
| 换行符 (Line Ending) | **Windows (CRLF)**（VS 默认） | 强制 |
| 文件末尾空行 | **必须保留一个空行** | 强制 |
| 函数/方法之间空行 | 统一空 **1 行**，但不强制检查 | 建议 |

### 括号与空格细化表

| 场景 | 写法细则 | 示例 |
| :--- | :--- | :--- |
| **关键字与 `(`** | 关键字后 **必须有一个空格** | `if (x > 0)` ✅ ； `if(x > 0)` ❌ |
| **函数调用** | 函数名与 `(` **无空格**；括号内侧 **无空格** | `Calculate(x, y)` ✅ ； `Calculate ( x, y )` ❌ |
| **函数声明/定义** | 函数名与 `(` **无空格**；括号内侧 **无空格** | `void Attack(Entity target)` ✅ |
| **逗号后** | 逗号后 **必须有一个空格**；逗号前 **无空格** | `Method(a, b, c)` ✅ |
| **索引/下标 `[]`** | 方括号内侧 **无空格**，紧贴索引 | `list[0]` ✅ ； `list[ 0 ]` ❌ |
| **数组/集合初始化 `{}`** | 花括号内侧 **必须有空格**；逗号后空格 | `int[] arr = { 1, 2, 3 };` ✅ |
| **代码块花括号 `{`** | 左花括号前 **必须有一个空格** | `if (x > 0) {` ✅ ； `if (x > 0){` ❌ |
| **二元/三元运算符** | 两侧 **必须各有一个空格** | `int Sum = A + B;` ✅ ； `int Sum=A+B;` ❌ |
| **一元运算符** | 与操作数 **无空格** | `++Index` ✅ ； `!IsReady` ✅ |
| **成员访问 `.` / `->`** | 两侧 **无空格** | `player.health` ✅ ； `ptr->next` ✅ |
| **作用域解析 `::`** | 两侧 **无空格** | `std::vector` ✅ |

## 第四章：C# 专属语言特性约束

| 规则项 | 规定 |
| :--- | :--- |
| `var` 关键字 | **任何地方都允许**（只要能过编译） |
| 字符串插值 | **强制使用 `$""`**（除非无法使用，如 .NET Framework 4.x 以下） |
| `using` 指令位置 | **强制放在命名空间外部**（文件最顶部） |
| `const` vs `readonly` | **优先使用 `const`**（类似 C++ 的 `constexpr` 语义） |
| 文件范围命名空间 | 除非需要多个命名空间嵌套，否则 **强制使用** `namespace MyNamespace;` |
| 顶级语句 (Top-level) | **单文件项目强制使用**，多文件/类库项目禁止使用 |
| 空值检查风格 | 不强制（`if (obj == null)` 或 `is null` 皆可） |
| `using static` | **完全允许** |
| 未使用的 `using` | **提交前必须删除**（VS 的“删除并排序”一键完成） |
| 文件头注释 | **完全不要**（无版权、无作者、无日期） |

## 第五章：C/C++ 专属语言特性约束

| 规则项 | 规定 |
| :--- | :--- |
| `auto` 关键字 | **鼓励使用**；存储 lambda 时 **必须使用 `auto`**（除非必须用 `std::function`） |
| `nullptr` vs `NULL` | **强制使用 `nullptr`**，彻底禁用 `NULL` 宏 |
| 头文件守卫 | **强制使用 `#pragma once`** |
| `const` 位置 | **左倾风格**：`const int& value` |
| `int` 与固定宽度类型 | 普通循环/计数器用 `int`；任何涉及序列化/跨模块/明确位宽场景 **强制使用 `int32_t`、`uint64_t`**；**严格禁止使用 `long` 表示位数意图**（必须改用 `int64_t`） |
| 原始指针 (`T*`) | 不强制智能指针，允许裸指针 |
| `#include` 顺序（.cpp 文件） | **所有 include 必须在最顶部**，顺序必须为：<br>1. 预编译头（如 `pch.h`）<br>2. STL 头文件<br>3. 外部依赖库头文件<br>4. 项目内部头文件 |
| `using namespace std;` | **绝对禁止**在头文件 (.h) 中出现；源文件 (.cpp) 中**仅允许在包含 `main` 函数的那个 .cpp 文件**中使用，其余 .cpp 一律禁止 |
| `using` 的使用 | 鼓励 `using` 在该文件中或项目中极为常见的类型或函数，例如`std::string` |

## 第七章：Unity 专用规则

| 规则项 | 规定 |
| :--- | :--- |
| `Awake` / `Start` / `Update` 顺序 | **必须严格按此顺序**书写，访问修饰符统一为 `private`（除非外部调用） |
| 空 `Update()` | **必须彻底删除**，禁止保留空函数体占位 |
| 高频循环字符串拼接 | 在 `Update` / `FixedUpdate` 中**禁止使用 `+`** 拼接，必须使用 `StringBuilder` 或预缓存 |
| 组件查找限制 | `GameObject.Find`、`GetComponent<T>` 等 **仅允许在 `Awake` / `Start` 中调用并缓存**，**严格禁止**在 `Update` 及任何每帧回调中调用 |

```csharp
// ==================== C# 控制台应用示例 ====================
// 文件: Program.cs (单文件项目，强制顶级语句)
using System;
using System.Collections.Generic;
using static System.Math;

const int MAX_RETRY_COUNT = 3;
int global_counter = 0;

Console.WriteLine("Starting...");
var player = new Player("Alice", 100);
player.Attack(10);
player.Heal(5);

for (int i = 0; i < 10; i++) {
	global_counter++;
	Console.WriteLine($"Count: {global_counter}");
}

namespace MyGame {
	public class Player {
		public string Name;
		private int Health;
		private int Experience;

		public const int MAX_HEALTH = 1000;
		public bool IsAlive { get; private set; }

		public Player(string name, int initial_health) {
			Name = name;
			Health = Clamp(initial_health, 0, MAX_HEALTH);
			IsAlive = true;
			Experience = 0;
		}

		public void Attack(int damage) {
			if (damage <= 0) {
				return;
			}

			int final_damage = damage;
			if (Experience > 50) {
				final_damage = (int)(final_damage * 1.2);
			}

			Health -= final_damage;
			if (Health <= 0) {
				Health = 0;
				IsAlive = false;
				OnDeath?.Invoke(this);
			}
		}

		public void Heal(int amount) {
			int new_health = Health + amount;
			Health = Min(new_health, MAX_HEALTH);
		}

		public event Action<Player> OnDeath;

		// switch/case 与 switch 平齐
		public string GetRank() {
			switch (Experience) {
			case int e when e < 100:
				return "Novice";
			case int e when e < 500:
				return "Veteran";
			default:
				return "Master";
			}
		}

		private int Clamp(int value, int min, int max) {
			if (value < min) return min;
			if (value > max) return max;
			return value;
		}
	}
}
// 最后添加空行
```
